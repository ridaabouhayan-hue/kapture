# Kapsure

Eigen screenshot-tool voor Windows 11. Bij elke screenshot snel noteren waarom je hem maakte.

- **Downloaden:** kijk bij Releases en kies `Kapsure-Setup.exe`.
- **Afspraken:** `BOUWPLAN.md`. **Ontwerp:** `docs/ontwerp/stitch/`. **Metingen:** `docs/SPIKE.md`.
- **Werken met Claude Code:** lees eerst `CLAUDE.md`.
- **Zelf bouwen op Windows:** `powershell -ExecutionPolicy Bypass -File build\build.ps1`
